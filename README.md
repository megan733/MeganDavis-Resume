# Megan Davis — Portfolio & Résumé

A personal portfolio for Megan Davis, Paid Media Strategist at GSF Media.

**Website:** https://megan733.github.io/MeganDavis-Resume/

## Features

- Responsive layouts with optimized professional photography.
- Selected projects across paid media, search, and e-commerce.
- An interactive lead-matchback example using clearly labeled sample data.
- Accessible navigation, project dialogs, and keyboard controls.
- A downloadable résumé and direct contact links.

Built with HTML, CSS, and JavaScript. No dependencies or build step required.

## Preview locally

Run `python -m http.server 8000` from this directory, then open http://localhost:8000.

## Edit

- `index.html` — content, experience, and contact information.
- `styles.css` — styling and responsive layouts.
- `script.js` — navigation, dialogs, and the reporting example.
- `assets/` — photographs, favicon, and résumé PDF.

## GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, then **Save**. All asset URLs support this repository's project URL.
